### Getting started

```bash
git clone https://github.com/Raimal-Raja/IBM-DataScience-Course.git
cd IBM-DataScience-Course
```

Open the relevant .ipynb notebook in Jupyter or a compatible notebook environment. Inspect its dependency and data-loading cells before running; there is no single shared application entry point.

### Configuration and limitations

Browse the chapter notes in order. This repository is study material rather than a deployed application; no model training or cloud provisioning was performed.
